ErgeHash 快速指南

ErgeHash（二哈）是一款 Windows 桌面文件哈希校验工具，基于 Tauri 2 + React/TypeScript 构建，哈希计算由 Rust 原生实现，速度快、资源占用低。当前版本 v0.3.0。

一、核心功能

计算哈希

  1. 添加文件：拖拽文件/文件夹到列表，或按 Ctrl+O 选文件、Ctrl+Shift+O 选文件夹。
  2. 选择算法：在左侧边栏勾选算法（可多选）。
  3. 开始计算：点击「开始校验」，或按 Ctrl+Enter。结果回填到文件列表，可逐条复制。

校验文件

  1. 准备预期哈希：两种方式任选其一——导入校验文件（Ctrl+I，支持 .md5/.sha256/.sfv 等），或在列表的预期哈希框中粘贴哈希值。
  2. 比对：点击「开始校验」，每行显示匹配 / 不匹配状态。

资源管理器右键菜单

安装后在文件上右键，可直接调用 ErgeHash：

  • 计算哈希：弹出报告窗显示所选文件的哈希值（可复制）。
  • 对比文件：多选文件后右键「对比文件」，报告窗列出全部文件并标明是否一致。
  • 校验文件：对校验文件右键，自动解析并比对。

二、支持算法

算法说明典型用途
SHA-256推荐（默认）文件完整性验证
SHA-512安全高安全需求
SHA-1兼容旧系统 / 历史兼容
MD5传统快速校验（不推荐用于安全场景）
CRC32校验和快速完整性 / 传输校验

三、快捷键

快捷键功能
Ctrl+O打开文件
Ctrl+Shift+O打开文件夹
Ctrl+I导入校验文件
Ctrl+Enter开始校验
Ctrl+Alt+C复制哈希结果
Ctrl+E导出结果
Ctrl+H历史记录
Ctrl+Alt+H清空历史
Ctrl+Alt+T切换主题
Ctrl+Alt+L切换语言
Ctrl+/打开本指南
Ctrl+B折叠 / 展开侧栏
Ctrl+,打开设置
Ctrl+Q退出
Ctrl+Shift+Backspace清空文件列表

四、主题与设置

  • 暗色模式：点击标题栏主题按钮可一键切换亮 / 暗，选择会自动保存，下次启动沿用。
  • 设置：按 Ctrl+, 打开设置，可切换主题、查看支持算法与版本信息。
  • 历史记录：Ctrl+H 查看最近计算记录，可快速重新计算历史文件。
