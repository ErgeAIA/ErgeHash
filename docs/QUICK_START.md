# HashValidatorPlus v0.1.0 - 使用指南

## 核心功能

### 单文件哈希计算

1. **打开文件**: 点击"添加文件"按钮或拖拽文件到文件列表
2. **选择算法**: 在左侧边栏选择算法 (SHA-256 / MD5 / SHA-1 / SHA-512)
3. **计算哈希**: 点击"开始批量校验"按钮
4. **查看结果**: 完整哈希值会显示在右侧面板

### 批量处理

1. **添加多个文件**: 拖拽多个文件或文件夹
2. **点击"开始批量校验"**: 自动处理所有文件
3. **暂停/继续**: 使用暂停/继续按钮控制进度
4. **查看结果**: 实时显示处理进度和结果

### 哈希校验

1. **输入预期哈希**: 在验证区域输入要校验的哈希值
2. **点击"比较哈希值"**: 对比计算结果
3. **查看比对结果**: 显示匹配/不匹配的状态

### 快速比较

1. **添加两个文件**: 拖拽两个文件到文件列表
2. **点击"快速比较"**: 自动比较两个文件的哈希值
3. **查看结果**: 显示文件是否相同
4. **大文件优化**: 文件大小超过1G时，只比较文件前5M的信息

## 支持的哈希算法

| 算法    | 标准 | 用途                       |
| ------- | ---- | -------------------------- |
| SHA-256 | 推荐 | 文件完整性验证（默认）     |
| SHA-512 | 安全 | 高安全需求                 |
| SHA-1   | 兼容 | 旧系统兼容                 |
| MD5     | 传统 | 快速验证（不推荐用于安全） |

## 快速技巧

### 拖拽加载

```
直接拖拽文件或文件夹到文件列表 → 自动添加
支持多文件/文件夹同时拖拽
```

### 批量校验技巧

- 拖拽整个文件夹自动加载所有文件
- 大文件会自动分块处理（81KB 每块）
- 相同文件自动使用缓存，加快处理速度

### 右键菜单

```
在文件列表中右键点击:
- 移除选中文件
- 清空所有文件
- 复制文件路径
```

### 复制结果

```
在结果面板中:
- 双击选中哈希值
- Ctrl+C 复制
- 或点击"复制"按钮
```

## 配置文件位置

配置和历史记录存储在:

```
%USERPROFILE%\.hashvalidatorplus\
├── config.json      # 应用设置
└── history.json     # 计算历史
```

**包含内容**:

- 选中的算法
- 主题偏好 (亮色/暗黑)
- 窗口大小和位置
- 最近 50 条计算记录

## 故障排除

### 问题: 没有看到暗黑模式按钮

- **解决**: 刷新或重启应用
- **检查**: 确保 main.py 已更新

### 问题: 计算器按钮无法打开计算器

- **解决**: 检查 Windows 系统是否有 calc.exe
- **备选**: 手动从开始菜单打开计算器

### 问题: 主题没有保存

- **解决**: 检查 `%USERPROFILE%\.hashvalidatorplus` 目录权限
- **备选**: 手动创建该目录

### 问题: 文件过大导致卡顿

- **原因**: 大文件需要更多处理时间
- **解决**:
  - 等待计算完成
  - 或点击"停止"按钮中止

## 性能指标

### 测试环境

- CPU: 现代多核处理器
- 内存: 4GB+
- 存储: SSD 优先

### 处理速度参考

- **1 GB 文件**: ~2-5 秒 (SSD)
- **100 MB 文件**: ~0.2-0.5 秒
- **10 MB 文件**: ~20-50 毫秒

### 缓存优化

- 相同文件重复计算时自动使用缓存
- 缓存密钥: `(文件大小, 算法)`
- 显著加快批量处理速度
